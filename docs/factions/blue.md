# Blue faction ("Tech") spec

Extracted from `reference/rise-of-legions/Scripts/Units/Blue`, `Scripts/Spells/Blue`, related Modifiers, Links and Projectiles, plus the Pascal component implementations. Numbers are exact. Use with `game/data/units.json` (the components are already extracted there); this doc explains what each group does.

## 0. Energy, gadgets and induction (faction-wide)

**Energy** is stored in **`reMana`** (integer, shown as "energy"). Unlike Black souls it does not arrive from deaths: units start full (or empty for induction units) and spend it as ammo. Sources: `AmmoFactory` transfer projectiles, the `Induction` triggers (`TAutoBrainOnCommanderAbilityUsedComponent.ConstraintOnSameTeamID.ConstraintOnInWelaRange.FireAtSelf`: any own-team spell cast with a target within `eiWelaRange` of the unit fires the group once, `Brains.pas:3103-3128`; the global `eiCommanderAbilityUsed` is raised by `TWelaEffectTriggerSpellCastComponent` in `SpellTemplate.dws:32`), `BlessingEnergy`, `AmmoRefill`, `Relocate`. Ammo welas pay with `TWelaReadyCostComponent/TWelaEffectPayCostComponent.SetPayingGroupForType(reMana, [])`.

**Gadgets** (`upGadget`: GatlingTurret, MissileTurret, AmmoFactory, ObserverDrone): commander resource `reGadgetCount` cap `Game.GadgetCountCap = 5` (`Scenarios/Game.dws:13`, `RES_IGNORE_CAP` so it can exceed). Every gadget has two groups: `TAutoBrainOnCreateComponent.FireAtCommander` → `TWarheadSpottyResourceComponent.SetResourceType(reGadgetCount)` (+1) and `TAutoBrainOnDeathComponent.FireAtCommander.ThinksPassively.ThinksInExile` → `.SetFactor(-1.0)` (−1). The *Building card* (`GatlingTurretBuilding.ets` etc.): `TAutoBrainOnCreateComponent([5]).FireAtTarget` → `TWelaReadyResourceCompareComponent.ComparedResource(reGadgetCount).CheckFull.ChecksCommander` → radial `tcAllies` range `10000` → `MustHave([upGadget])` → `TWelaEfficiencyCreatedComponent` → `TWarheadSpottyKillComponent.Sacrifice`. **Placing a 6th gadget sacrifices the oldest one** (same pattern as the charm cap 3, `Game.dws`). Gadgets use `InitBuildingData(Entity)` (no lifetime) and are `atFortified`.

**Missiles** (`Projectiles\Blue\Missile.ets`, inherited via `InheritsFromPreceding` by `AegisMissile`, `AirdominatorMissile`, `InductionerMissile`, `MissileTowerMissile`): speed `20/1000`, `eiWelaModifier[1] = 2.0`; group 0 `TBrainProjectileComponent.NoTargetChecks` → `Enemies` + `Event(eiDamageable)` + `MustNotHave([upBanished])` → instant → `TWarheadSplashDamageComponent` (AoE copied from launcher, 2.5 everywhere); `TModifierMultiplyDealtDamageComponent([0]).MustNotHave([dtSpell]).CheckWelaConstraint.SetValueGroup([1])` gated by group 1 `MustHaveAny([upFlying, upMonumental])`. **Anti-air: ×2 damage against flying/monumental targets.**

**Gatling links** (`Links\GatlingLinkBase.ets`, inherited by `GatlingLink`, `GatlingTowerLink`, `AegisGatlingLink{Front,Left,Back,Right}`): `eiDamageType[1] = [dtSplash, dtRanged]`, `eiWelaDamage[1] = 3.0`, `eiWelaAreaOfEffect[1,2] = 2.5`. `TLinkBrainComponent([0,1,2])` fires every `eiCooldown` (read through `TLinkEventRedirecter` from the owner's wela group: `eiCooldown`, `eiWelaDamage`, `eiDamageType`, `Welas.pas:683-687,922-933`): group 0 `TWarheadSpottyDamageComponent` (owner damage, "Surefire", cannot miss blinded: owners are `upImmuneToBlinded`) and group 1 `TWarheadSplashDamageComponent` (3 splash in 2.5, "Searching Fire"). Constraints [0,1]: `Enemies`, `Event(eiDamageable)`, `MustNotHave([upBanished])`.

## 4. Component semantics (Pascal) — not yet in `wela.gd` / `buff.gd`

**`TWelaEffectLinkPayCostMyselfComponentServer`** (`Server.Welas.pas:613, 2253-2331`) — ready+effect on the link owner. `OnLinkEstablish`: if no link was active, `Pay(1)` immediately and start the timestamp; `OnThink` (needs a think impulse): `Pay(elapsed div 1000)` keeping the remainder; `OnLinkBreak` of the last link settles the elapsed seconds. `Pay` triggers `eiResourceTransaction(-cost·times)`; if a resource went from >0 to ≤0 it fires `eiFire(self)` in `FireOnEmpty(group)`. Extends `TWelaReadyCostComponent` (not ready when unaffordable → link breaks).

**`TBrainWelaLinkComponent.LinkTime(ms)`** (`Brains.pas:1329, 1370-1389`) — link brain's build timer (default `DEFAULT_LINK_BUILD_TIME = 250`). Each think: drop invalid targets; when the timer expired and the group is ready, re-query targets and `eiFire` (establish links), then restart the timer. `Preemptive` → `eiStand` while linked.

**`TWelaTargetingRadialComponent.Cone(dirX, dirZ, angle)`** (`Welas.pas:1653-1668, 1724-1731`) — candidate rejected unless `InnerAngle(coneDir, dirToEntity) − arctan(radius/dist) ≤ angle/2`; direction is in world space (Aegis is `FixedOrientation`). `.RangeFromEvent(ei)` reads the range from another blackboard event (`eiAttentionRange`).

**`TWelaLinkEffectComponent.CreatorGroup(g)`** (`Welas.pas:1508, 1556`) — written as `eiCreatorGroup` into the spawned link entity; `TWarheadLinkApplyScriptComponent` (`Shared.Wela.pas:918, 2580-2599`) applies the `.dws` to the link's destination on `eiAfterCreate` (if `eiWelaTargetPossible`), stores creator/creator-group on the applied groups and removes them when the link entity is freed. `TWelaEffectFireComponent.FireInCreator` (`Welas.pas:2843, 2878`) fires the component group in the creator entity instead of the owner.

**`TLinkBrainComponent`** (`Server.pas:150, 1538-1575`) — on the link entity: timer = `eiCooldown` (redirected to the owner group); when expired fires `eiFire(eiLinkDest)` `TimesExpired(50)` times if target still valid. `TLinkEventRedirecter` (`Welas.pas:677-689`) forwards empty reads of `eiCooldown/eiWelaDamage/eiDamageType` to the link source's wela group and reports `eiDamageDone` back to it.

**`TAutoBrainOnCommanderAbilityUsedComponent`** (`Brains.pas:729, 3103-3140`) — global `eiCommanderAbilityUsed(TeamID, Targets)`; requires `CanThink`; `ConstraintOnSameTeamID`; `ConstraintOnInWelaRange`: some target position within `eiWelaRange` of the owner; then `CheckAndFire(Targets)` (`FireAtSelf` redirects to owner).

**`TWelaReadyEntityNearbyComponent`** (`Welas.pas:234, 3199-3225`) — ready iff the targeting in `TargetingGroup(g)` returns targets (`ReadyIfTargets`) or none (`ReadyIfNoTargets`). **`TWelaTargetingSelfComponent`** (`:3229`) — target list = owner. **`TThinkImpulseOnceComponent.TriggerOnDeploy`** (`Brains.pas:2396`) — single think on `eiDeploy`.

**`TBrainFollowComponent`** (`Brains.pas:252`, = `TBrainApproachComponent`, `:1572-1620`) — moves to `range + own radius + target radius − 0.1` of the first target each think; **`TBrainWaitComponent`** (`:314, 1270-1287`) — if its targeting finds anything, `eiStand` and break the think chain.

**`TWelaTriggerCheckNotSelfComponent`** (`Shared.Wela.pas:540, 3198`) — take-damage trigger valid only if `InflictorID <> Owner.ID`. **`TAutoBrainOnTakeDamageComponent.TriggersAfterDamage`** (`Brains.pas:2633`) — moves the hook to `epLast` (after the health was reduced, so `ThinksPassivelyIfConscious` sees the unit alive).
**`ThinksPassivelyIfConscious`** (`:2136, 2104-2114`) — like `ThinksPassively` but `CanThink` still applies (stunned/ frozen units don't think). **`ThinksLocal`** (`:2124`) — think chain is not shared with other groups.

**`TWelaEffectActivationAbilityComponent.SetCheckGroup/CheckNotFull/TriggerOnReachResourceCap`** (`Welas.pas:2677-2734`) — on fire, reads balance/cap of `FResType` in the check group; `TriggerOnReachResourceCap` sets active state only when balance = cap (default state False → deactivates), `CheckNotFull` when balance ≠ cap; writes `eiWelaActive` of the activation group if it changes.

**`TWarheadSpottyResourceComponent`** (`Warheads.pas:390-475`) — `.SetFactor(f)` multiplies the amount; `.AmountIsPercentage` treats `eiWelaDamage` as a fraction of the target's `eiResourceCap` (rounded for int resources); `.ResetResource` triggers `eiResourceReset` (balance := cap) instead of a transaction. **`TWarheadSpottyWelaStopComponent`** (`:1226`) — triggers `eiWelaStop` on the target. **`TWarheadSpottyRemoveBuffComponent.All`** (`:1070`) — must-have-any = all buff types.

**`TWarheadSplashDamageComponent.LineFromOwner(width)`** (`:692-714, 747`) — replaces the circle by a segment from the owner along `Front·AoE`; hits entities whose distance to the segment minus their radius is ≤ width/2.

**`TWarheadSpottyTeleportComponent.OffsetByCollisionRadius.Offset(d)`** (`:939, 1007-1018`) — lands at `target + normalize(self − target)·(d + targetRadius + ownRadius)`; entity is exiled and re-ID'd (`eiReplaceEntity`) so all targeting on it is dropped. `.ToCoordinate(x, y)` teleports to a fixed point.

**`TWelaReadyCooldownComponent.Cooldown(ms).Once`** (`Shared.Wela.pas:1924, 1972-1981`) — fixed interval independent of `eiCooldown`; `Once`: after the first ready it stays ready forever (one-time delay).
